# Sandbag Siege – ทหารกล้า ป้องกันฐาน

A portrait, mobile-first classic tower-defense web game. It is a single self-contained HTML file: all art is drawn in code and it makes no network requests.

Enemy troops, jeeps, APCs, tanks, helicopters and a boss tank march along the road toward your HQ. Tap sandbag pads to buy gun emplacements (Rifleman, Machine gun, Sniper, Mortar, Rocket, Flamethrower, Anti-air, Tesla), tap dropped coins to collect them, upgrade guns to level 3, and clear 3 maps for up to 3 stars each.

Play (v2 – realistic look, short roads, zoomed-in): https://pawineenueangnin-oss.github.io/sandbag-siege/

v1 (original cartoon version): https://pawineenueangnin-oss.github.io/sandbag-siege/v1.html
